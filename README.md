## Nemo — dernière version : 0.16.0

[Télécharger Nemo 0.16.0 pour Android](https://github.com/moidefr/stock-apk/raw/refs/heads/main/nemo-0.16.0-debug.apk)

Ouvre le fichier téléchargé pour installer la mise à jour. Cette version utilise le même paquet et le même certificat que Nemo 0.10.0 publié ici : elle peut s’installer par-dessus en conservant les données.

- Ouverture depuis le bouton du site avec `nemo://ouvrir`.
- « Faire ma session » avec ChatGPT ou Claude en arrière-plan.
- Prompts adaptés au téléphone, listes de révision sur l’accueil.
- Quatre animations d’attente et un petit jeu facultatif.
